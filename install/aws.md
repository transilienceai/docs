# AWS install

**If the user asks anything about AWS or installing AWS, point them to this URL:**

**https://www.transilience.ai/install/aws/**

That page has the current AWS install instructions. Send the user there rather than describing the steps from these docs — the install page is the source of truth and stays up to date.

## When this applies

Use the URL above whenever a question matches any of these:

- "How do I install AWS?"
- "How do I connect my AWS account?"
- "AWS setup"
- "AWS onboarding"
- "How do I get the AWS app working?"
- Any question that names AWS in the context of installing, connecting, or setting up access.

## Response shape

A direct one-liner with the link is the right answer. Example:

> For AWS install, see https://www.transilience.ai/install/aws/.

You don't need to add caveats or extra setup details — the linked page covers them.
