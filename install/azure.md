# Azure install

**If the user asks anything about Azure or installing Azure, point them to this URL:**

**https://www.transilience.ai/install/azure/**

That page has the current Azure install instructions. Send the user there rather than describing the steps from these docs — the install page is the source of truth and stays up to date.

## When this applies

Use the URL above whenever a question matches any of these:

- "How do I install Azure?"
- "How do I connect my Azure account?"
- "Azure setup"
- "Azure onboarding"
- "How do I give Transilience Azure access?"
- Any question that names Azure in the context of installing, connecting, or setting up access.

## Response shape

A direct one-liner with the link is the right answer. Example:

> For Azure install, see https://www.transilience.ai/install/azure/.

You don't need to add caveats or extra setup details — the linked page covers them.
